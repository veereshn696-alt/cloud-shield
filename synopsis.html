1. Abstract

Modern digital organizations rely heavily on cloud applications, web services, and APIs. However, every digital action generates large streams of audit logs, making manual monitoring impossible. Without automated detection, critical cyberattacks—including brute-force credential stuffing, Distributed Denial of Service (DDoS), privilege escalation, and anomalous proxy logins—can proceed undetected until catastrophic damage occurs.

CloudShield is an intelligent, multi-tenant cloud security monitoring and threat detection platform (Mini SIEM) built as a Freemium Software-as-a-Service (SaaS) solution. It enables multiple client organizations to register, connect remote applications, ingest activity logs in real time, and evaluate events against an automated security detection engine. The platform operates on a freemium model: core audit logging and rule-based threat mitigation are provided free of cost, while advanced features—including AI/ML anomaly detection and deep forensics—are unlocked via paid subscription tiers. Containerized with Docker, CloudShield offers high scalability, minimal latency, and full cloud portability.

2. Introduction & Background

Security Information and Event Management (SIEM) systems serve as the operational core of modern Security Operations Centers (SOC). However, traditional enterprise SIEM platforms (e.g., Splunk, IBM QRadar) demand expensive on-premise hardware, specialized system engineers, and complex licensing, creating an insurmountable barrier for small-and-medium enterprises (SMEs) and academic labs.

By adopting Security as a Service (SECaaS) and cloud multi-tenancy, a single centralized monitoring infrastructure can serve multiple independent organizations simultaneously. Each tenant organization maintains complete logical data isolation while benefiting from high-availability cloud compute resources and automated threat response.

3. Problem Statement

  • Information Overload: Cloud platforms generate thousands of events per minute; manual inspection of audit logs is impossible.
  • Prohibitive Commercial Cost: Existing commercial SIEM solutions impose heavy infrastructure costs, excluding small businesses and startups.
  • Delayed Incident Response: Most monitoring tools analyze logs post-incident in batch cycles rather than performing sub-second, real-time threat mitigation.
  • Lack of Academic Demonstration Platforms: Most security tools are closed proprietary black boxes, making it difficult for students and researchers to safely simulate and observe live cyberattacks.

4. Objectives of the Project

  1. Design a Multi-Tenant Cloud Architecture: Support multiple tenant organizations with strict logical data isolation on a shared cloud database.
  2. Real-Time Log Ingestion: Centralize event audit streams capturing action codes, timestamps, IPv4 addresses, user agents, and status.
  3. Automated Detection Engine: Implement real-time sliding-window algorithms to detect Brute Force attacks, DDoS surges, unauthorized escalation, and Tor proxy IPs.
  4. Freemium Feature Gating: Enforce server-side authorization separating free-tier basic features from paid-tier advanced AI analytics.
  5. Interactive SOC Dashboard: Provide real-time security visibility with aggregate metric counters, live severity-coded alert feeds, and audit log tables.
  6. Real-Time Live Ingestion Gateway: Build an authentic REST API endpoint (POST /api/v1/events) and standalone client agent (agent.py) enabling external servers and cloud workloads to stream real security events over HTTP.
  7. Cloud Portability & Containerization: Package the microservice using Docker and Docker Compose for instant cloud deployment (AWS/Azure).

6. Key Modules & Functional Description

  • Module 1: Company & Multi-Tenant Management: Isolates company accounts using unique company_id keys, ensuring absolute data privacy between tenants.
  • Module 2: Authentication & Cryptographic Security: Employs SHA-256 cryptographic one-way hashing to protect user credentials and enforces role-based permissions (Admin vs. User).
  • Module 3: Centralized Audit Logging (SIEM Vault): Ingests and stores comprehensive audit records using parameterized SQL execution to prevent SQL injection.
  • Module 4: Real-Time Detection Rule Engine:
    • Brute Force Rule (CRITICAL): Triggers when ≥ 3 failed logins occur from the same IP/username in 5 minutes.
    • DDoS Surge Rule (HIGH): Triggers when ≥ 15 HTTP requests arrive in 60 seconds from a single IP.
    • Privilege Escalation Rule (HIGH): Alerts when unprivileged users attempt restricted administrative routes.
    • Tor / Malicious Proxy Rule (MEDIUM): Flags logins originating from known Tor exit nodes (e.g., 185.220.*).
  • Module 5: AI / Machine Learning Anomaly Detection (Pro Tier): Leverages Scikit-Learn Isolation Forests to detect statistical anomalies in user request volume and abnormal login hours.
  • Module 6: Freemium Subscription Gating: Gating engine with Free (₹0), Professional (₹999), and Enterprise plans, complete with a test sandbox upgrade simulator.
  • Module 7: Cyber SOC Dashboard: Live dashboard with 3-second asynchronous polling, severity-coded threat cards, and one-click alert resolution.
  • Module 8: Real-Time Event Ingestion Gateway & Terminal Agent: Authentic live HTTP ingestion API with API key authentication, live browser dispatcher, and standalone Python streaming client (agent.py).
