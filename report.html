Chapter 1: Introduction

1.1 Project Overview

In today's interconnected digital economy, cloud computing serves as the primary infrastructure for web applications, microservices, and mobile backends. Every digital interaction produces audit logs. Without automated threat detection, malicious activities such as brute-force credential stuffing, Distributed Denial of Service (DDoS), and privilege escalations often go unnoticed until severe data compromise occurs.

CloudShield is an intelligent, multi-tenant cloud security monitoring and threat detection platform (Mini SIEM) built as a Freemium Software as a Service (SaaS) platform. It allows multiple organizations to register, connect applications, ingest audit logs in real time, evaluate events against automated detection rules, and visualize security postures on a SOC dashboard.

1.2 Problem Statement

  • Information Overload: Cloud platforms generate thousands of events per minute; manual inspection is impossible.
  • High Cost of Commercial SIEM: Enterprise tools (Splunk, QRadar) demand massive licensing budgets, excluding startups and SMEs.
  • Delayed Response: Traditional tools analyze logs in batch cycles hours after an attack has concluded.
  • Lack of Academic Testbeds: Proprietary tools lack safe simulation environments for security analysis and education.

1.3 Objectives

  1. Implement a Multi-Tenant Architecture with strict logical data isolation by company_id.
  2. Build a Real-Time Ingestion Engine capturing action, IP, username, status, and timestamps.
  3. Develop an Automated Detection Engine detecting Brute Force, DDoS, and Privilege Escalation within milliseconds.
  4. Create an AI Anomaly Scoring Model evaluating multidimensional behavioral deviations.
  5. Implement a Freemium Feature-Gating Mechanism separating Free (₹0) from Pro (₹999) tiers.
  6. Containerize the microservice with Docker for cloud portability.

Chapter 4: Conclusion & Future Scope

CloudShield successfully demonstrates the convergence of Cloud Computing (multi-tenancy, SaaS model, Docker containerization) with Cybersecurity (centralized SIEM audit logs, automated rule engine, and machine learning behavioral scoring).

Future scope includes automated integration with public cloud firewalls (AWS Security Groups / Cloudflare WAF) to automatically ban attacker IPs at the cloud boundary, as well as multi-region PostgreSQL clustering for high-throughput enterprise scale.
