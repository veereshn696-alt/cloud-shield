📐 Architecture & Academic Viva Defense Guide

1. Multi-Tenant Cloud SaaS Model

CloudShield acts as a central cloud host. Multiple tenant companies securely share a single centralized database and backend logic, partitioned cleanly by company_id to guarantee 100% logical data isolation.

2. Freemium Security Gating

Basic audit logging and rule-based threat mitigation are provided free of cost (₹0/mo). Advanced capabilities—such as AI/ML Anomaly Detection—are securely feature-gated on the backend and unlocked when upgrading to the Professional plan.

3. Threat Detection Rules

  • Brute Force Rule: ≥ 3 failed login attempts from same IP in 5 mins → Critical Alert.
  • DDoS Surge Rule: ≥ 15 HTTP requests in 60 seconds from single IP → High Alert.
  • Privilege Escalation Rule: Unauthorized endpoint access attempt → High Alert.
  • Tor / Malicious Proxy Rule: Logins from recognized Tor exit node IPs → Medium Alert.

CloudShield includes a standalone, zero-dependency Python client agent (agent.py) that streams authentic security events over the network in real time.

1. Terminal Agent Quick Commands

# Transmit Real Live Attack Traffic (Over HTTP API)

2. Ingest Events via cURL (Any Server / VM)

curl -X POST http://127.0.0.1:8000/api/v1/events \
  -H "Content-Type: application/json" \
  -H "X-API-Key: acme_sec_live_9921" \
  -d '{
    "action": "LOGIN_FAILED",
    "username": "admin",
    "ip_address": "192.168.1.105",
    "status": "FAILURE",
    "details": "Rapid invalid password trial"
  }'

3. Connect Python Web Applications (FastAPI / Flask / Django)

import urllib.request, json

def push_cloudshield_audit(action, username, ip, status, details):
    payload = json.dumps({
        "api_key": "acme_sec_live_9921",
        "action": action,
        "username": username,
        "ip_address": ip,
        "status": status,
        "details": details
    }).encode("utf-8")
    req = urllib.request.Request(
        "http://127.0.0.1:8000/api/v1/events",
        data=payload,
        headers={"Content-Type": "application/json"}
    )
    urllib.request.urlopen(req)
